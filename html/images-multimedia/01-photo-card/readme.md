# Photo Card

## Problem

Create a profile card that presents a person’s photo, name, and short description in a clear, structured layout.

## Requirements

* [x] Create the card structure with HTML
* [x] Add a profile image
* [x] Provide meaningful `alt` text
* [x] Add the person's name
* [x] Add a short description
* [x] Style the card with CSS
* [x] Test the result in the browser

## Concepts Applied

* HTML document structure
* `<img>`, `src`, and `alt`
* Semantic grouping with `<figure>` and `<figcaption>`
* CSS sizing and spacing
* Borders and card styling
* Typography

## Implementation

* Built the card using a semantic `<figure>` containing the profile image and `<figcaption>` for the person's name and description.
* Added the profile image with `<img>`, using `src` to reference the image file and `alt` to describe the image.
* Used CSS to set the image dimensions, add spacing and borders, and style the card's text and overall appearance.

## Challenges & Solutions

**Challenge:** Keeping the profile image at a consistent size.

**Solution:** Set explicit width and height values in CSS to control the image dimensions and maintain the card layout.
