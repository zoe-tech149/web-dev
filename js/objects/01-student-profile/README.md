# JavaScript Objects — Evolving Program

## Purpose

This is one evolving program used to learn and apply JavaScript Objects.

Instead of creating a separate project for every new Objects concept, the program changes as new concepts are learned and new problems need to be solved.

The Git history documents how the program evolves over time.

## Current Problem

The program currently works with information about a student.

It stores student information in a JavaScript object and displays that information on a webpage.

## Concepts Learned

- JavaScript objects
- Object properties
- Accessing object properties
- Displaying object values with `textContent`
- Deleting object properties with the `delete` operator
- Updating the webpage when object data changes

## Evolution

### Current Stage — Student Information

The program stores information about a student using an object.

It can access individual properties, display their values on the webpage, and remove a property from the object.

As new JavaScript Object concepts are learned, the program will evolve to solve more complex problems.

## Learning Approach

Each new concept follows this process:

1. Learn the concept.
2. Understand why it is useful.
3. Identify a problem the current program cannot solve.
4. Use the new concept to improve the program.
5. Test the change.
6. Explain what changed and why.
7. Commit the change to Git.
8. Record a Loom demonstration when the change represents a meaningful stage.

## Git History

Git commits are used to document the evolution of the program.

Each meaningful change should explain what was learned or what problem was solved.

## Future Evolution

The program will continue to change as new Object concepts are learned.

The current problem, program name, and capabilities may change when the program grows beyond its original purpose.
