# JavaScript Conditionals — Evolving Program

## Purpose

This is one evolving program used to learn and apply JavaScript conditional logic.

Instead of creating a separate project for every new conditional concept, the program changes as new concepts are learned and new problems need to be solved.

The Git history documents how the program evolves over time.

## Current Problem

The program currently determines whether a person is eligible based on their age.

The user enters an age, the program validates the input, and conditional logic determines the result.

## Concepts Learned

- `if` statements
- Comparison operators in conditions
- Logical decision-making
- `return` statements
- Input validation
- Combining validation with conditional logic
- Updating webpage content based on a condition
- Event listeners and user interaction

## Current Stage — Age Eligibility

The program currently accepts a user's age and determines whether they meet the required age.

The program also handles missing and invalid input.

As new JavaScript Conditional concepts are learned, the program will evolve to solve more complex problems.

## Learning Approach

Each new concept follows this process:

1. Learn the concept.
2. Understand why it is useful.
3. Identify a problem the current program cannot solve.
4. Use the new concept to improve the program.
5. Test the change.
6. Explain what changed and why.
7. Commit the change to Git.
8. Record a Loom demonstration when the change represents a meaningful stage.

## Git History

Git commits document how the program changes as new Conditional concepts are learned and new problems are solved.

## Future Evolution

The program will continue to evolve as new JavaScript Conditional concepts are learned.

The current problem, program name, and capabilities may change when the program grows beyond its original purpose.
