# Age Eligibility Checker

## Problem

A simple web application that determines whether a user meets a minimum age requirement.

## Features

- Accepts an age from the user
- Validates empty input
- Validates age range
- Rejects decimal ages
- Checks eligibility against the minimum age
- Supports button clicks
- Supports the Enter key
- Clears stale results when the input changes

## Validation Rules

- Age must be entered
- Age must be between 0 and 120
- Age must be a whole number
- Minimum eligible age is 18

## What I Learned

This project helped me practice breaking a real-world problem into smaller responsibilities and solving each part with focused functions.

I also learned how JavaScript connects user input, application logic, and DOM updates.

## Challenges

One of the main challenges was separating the eligibility decision from the rest of the application logic.

I extracted validation and eligibility into separate functions so each function has a clear responsibility.
