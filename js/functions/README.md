# JavaScript Functions — Evolving Program

## Purpose

This is one evolving program used to learn and apply JavaScript functions.

Instead of creating a separate project for every new Functions concept, the program changes as new concepts are learned and new problems need to be solved.

The Git history documents how the program evolves over time.

## Current Problem

The program currently calculates an electricity bill based on the amount of electricity used.

## Concepts Learned

- Declaring functions
- Calling functions
- Function parameters
- Function arguments
- Returning values with `return`
- Using functions to divide a problem into smaller parts
- Returning multiple related values from a function
- Using function results in other parts of the program

## Current Stage — Electricity Bill Calculator

The program calculates the cost of electricity using different usage tiers.

Functions are used to separate the calculation into smaller problems and return the results needed by the program.

## Learning Approach

Each new concept follows this process:

1. Learn the concept.
2. Understand why it is useful.
3. Identify a problem the current program cannot solve.
4. Use the new concept to improve the program.
5. Test the change.
6. Explain what changed and why.
7. Commit the change to Git.
8. Record a Loom demonstration when the change represents a meaningful stage.

## Git History

Git commits document how the program changes as new concepts are learned and new problems are solved.

## Future Evolution

The program will continue to evolve as new JavaScript Function concepts are learned.

The current problem, program name, and capabilities may change when the program grows beyond its original purpose.
