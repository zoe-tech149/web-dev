# JavaScript Arrays — Evolving Program

## Purpose

This is one evolving program used to learn and apply JavaScript Arrays.

Instead of creating a separate project for every new Arrays concept, the program changes as new concepts are learned and new problems need to be solved.

The Git history documents how the program evolves over time.

## Current Problem

The program currently manages a grocery list.

It stores grocery items in an array and allows the user to interact with the list through the webpage.

## Concepts Learned

- JavaScript arrays
- Creating arrays
- Accessing array elements
- Adding items to an array
- Removing items from an array
- Editing items in an array
- Displaying array data on a webpage
- Working with arrays and the DOM

## Current Stage — Grocery List

The program currently allows the user to:

- View grocery items
- Add grocery items
- Remove grocery items
- Edit grocery items
- Give feedback when a duplicate item is entered

As new JavaScript Array concepts are learned, the program will evolve to solve more complex problems.

## Learning Approach

Each new concept follows this process:

1. Learn the concept.
2. Understand why it is useful.
3. Identify a problem the current program cannot solve.
4. Use the new concept to improve the program.
5. Test the change.
6. Explain what changed and why.
7. Commit the change to Git.
8. Record a Loom demonstration when the change represents a meaningful stage.

## Git History

Git commits document how the program changes as new concepts are learned and new problems are solved.

## Future Evolution

The program will continue to evolve as new Array concepts are learned.

The current problem, program name, and capabilities may change when the program grows beyond its original purpose.
