# JavaScript Loops — Evolving Program

## Purpose

This is one evolving program used to learn and apply JavaScript loops.

Instead of creating a separate project for every new Loops concept, the program changes as new concepts are learned and new problems need to be solved.

The Git history documents how the program evolves over time.

## Current Problem

The program currently helps track study sessions.

The user can interact with the program while loop-based logic processes and updates the study-session data.

## Concepts Learned

- `for` loops
- Repeating an operation using a loop
- Using loops to process multiple values
- Combining loops with conditions
- Using loops with arrays
- Updating webpage content from loop results

## Current Stage — Study Session Tracker

The program currently uses loops to process study-session information and present results to the user.

As new JavaScript Loop concepts are learned, the program will evolve to solve more complex problems.

## Learning Approach

Each new concept follows this process:

1. Learn the concept.
2. Understand why it is useful.
3. Identify a problem the current program cannot solve.
4. Use the new concept to improve the program.
5. Test the change.
6. Explain what changed and why.
7. Commit the change to Git.
8. Record a Loom demonstration when the change represents a meaningful stage.

## Git History

Git commits document how the program changes as new Loop concepts are learned and new problems are solved.

## Future Evolution

The program will continue to evolve as new JavaScript Loop concepts are learned.

The current problem, program name, and capabilities may change when the program grows beyond its original purpose.
