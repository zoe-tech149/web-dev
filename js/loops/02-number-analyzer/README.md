# Number Analyzer

## Problem

People often need to analyze a collection of numbers to understand
basic information such as the total, average, highest value, and
lowest value.

Doing these calculations manually becomes inefficient as the number
of values increases.

## Goal

Build an interactive web application that allows a user to enter
multiple numbers and analyze the collection.

The application should:

- Accept numbers from the user
- Display the numbers that have been entered
- Calculate the total
- Calculate the average
- Find the highest number
- Find the lowest number

## Programming Problem

The application needs to process every number in a collection and
calculate information about the entire collection.

This requires repeated processing of data, making loops an important
part of the solution.

## Technologies

- HTML
- CSS
- JavaScript

## Learning Focus

The main JavaScript focus of this project is loop-based problem solving.
